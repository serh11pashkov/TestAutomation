## 📌 Опис проєкту
Проєкт реалізує бізнес-логіку підрахунку вартості замовлень інтернет-магазину та функцію злиття однакових товарних позицій (`mergeItems`) з повним покриттям модульними тестами у фреймворку **Vitest**.

### Реалізований функціонал (`src/order.ts`):
1. **`calcSubtotal(items)`** — підсумовування вартості позицій з урахуванням кількості та валідацією на від'ємні ціни / некоректні кількості.
2. **`calcDiscountRate(tier, subtotal, promoRate)`** — розрахунок сумарної ставки знижки за рівнем клієнта (`basic`, `silver`, `gold`), бонусом за велике замовлення ($\ge 2000$ грн) та обмеженням граничної знижки до 25%.
3. **`calcShipping(amount)`** — розрахунок вартості доставки (безкоштовно від 1000 грн, інакше 60 грн).
4. **`calcOrderTotal(items, tier, promoRate)`** — комплексний розрахунок фінальної суми до сплати.
5. **`mergeItems(items)` (Варіант 8)** — дедуплікація та об'єднання однакових позицій за полем `sku` із підсумовуванням кількості `qty`, контролем цілісності цін (`PRICE_MISMATCH`) та перевіркою коректності вхідних даних (`EMPTY_ITEMS`, `INVALID_SKU`, `NEGATIVE_PRICE`, `INVALID_QTY`).
