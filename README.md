## Встановлення та запуск

```bash
# Встановлення залежностей
npm install

# Запуск модульних та інтеграційних тестів
npm test

# Запуск тестів з аналізом тестового покриття
npm run coverage

# Перевірка стилю коду
npm run lint

# Автоформатування
npm run format
```
