---

## Встановлення та запуск

```bash
# Встановлення залежностей
npm install

# Запуск REST API сервера
npm start

# Запуск автоматизованих тестів Supertest та Vitest
npm test

# Запуск тестів з аналізом покриття коду
npm run coverage

# Запуск Postman-колекції через Newman
npm run test:newman

# Перевірка стилю коду
npm run lint

# Форматування коду
npm run format
```
