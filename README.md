## Специфікація модуля (Варіант № 8)
- 100 хвилин включено в базовий пакет.
- Понад 100 хвилин — 0,50 грн за кожну наступну хвилину.
- Міжнародні дзвінки — 3,00 грн за кожну хвилину (не покриваються пакетом).
- Фіксована щомісячна абонплата — 150,00 грн.
- Додаткові опції: програма лояльності (знижка 10% на підсумковий рахунок).
- Валідація: відхилення від’ємних та дробових значень хвилин.
- Округлення: банківське заокруглення результату до двох знаків після коми (копійки).

---

## Встановлення та запуск

```bash
# Встановлення залежностей
npm install

# Запуск тестів
npm test

# Запуск тестів у режимі відстеження (watch mode)
npm run test:watch

# Запуск тестів з аналізом тестового покриття коду
npm run coverage

# Перевірка коду лінтером (ESLint)
npm run lint

# Автоматичне форматування коду (Prettier)
npm run format
```
