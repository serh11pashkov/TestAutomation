## Опис проекту
У лабораторній роботі реалізовано набір E2E-тестів на базі фреймворку **Playwright** та **TypeScript** для веб-додатку [SauceDemo](https://www.saucedemo.com).

### Реалізовані сценарії:
1. **Авторизація (`tests/login.spec.ts`)**:
   - Успішний вхід стандартного користувача (`standard_user`).
   - Валідація помилки при спробі входу заблокованого користувача (`locked_out_user`).
   - Валідація обов'язковості полів (порожній username/password).
2. **Каталог товарів (`tests/inventory.spec.ts`)**:
   - Перевірка відображення карток товарів та сортування (A-Z, Z-A, за ціною).
   - Додавання та видалення товарів з кошика безпосередньо з каталогу.
   - Оновлення лічильника кошика (badge).
3. **Оформлення замовлення (Варіант 8) (`tests/checkout.spec.ts`)**:
   - Перехід до `checkout-step-one.html`.
   - Негативний сценарій: спроба продовжити з порожнім полем "Last Name" (`Error: Last Name is required`).
   - Перевірка відсутності несанкціонованого переходу на `checkout-step-two.html`.
   - Позитивне відновлення: внесення прізвища та успішний перехід на сторінку огляду замовлення (`Checkout: Overview`).
4. **Експерименти та локатори (`tests/experiment.spec.ts`, `tests/broken.spec.ts`)**:
   - Порівняння семантичних користувацьких локаторів (`getByRole`, `getByPlaceholder`, `getByText`) із крихкими XPath / CSS селекторами.
   - Демонстрація стабільності тестів проти змін верстки.

## Встановлення та запуск

1. Встановлення залежностей:
   ```bash
   npm install
   ```

2. Встановлення браузерів Playwright (якщо не встановлено):
   ```bash
   npx playwright install chromium
   ```

3. Запуск усіх тестів у headless режимі:
   ```bash
   npm test
   # або
   npx playwright test
   ```

4. Запуск тестів з візуальним UI / переглядом звіту:
   ```bash
   npx playwright test --ui
   npx playwright show-report
   ```
